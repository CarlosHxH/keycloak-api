Painel do Mock Keycloak

Uso de contingência: este servidor assina tokens para qualquer identidade configurada aqui. Aponte sistemas para ele só durante a manutenção do Keycloak e volte a URL ao normal em seguida.

Importar access token

Cole um access token emitido pelo Keycloak real (ex.: copiado do navegador antes da manutenção). O mock passa a emitir tokens com o mesmo usuário, sub e roles. A assinatura e a validade do token colado não são verificadas: só os dados dele são usados.
